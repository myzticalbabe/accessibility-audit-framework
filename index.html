Core Accessibility Checks

WCAG 2.1 aligned checks implemented in the framework

Check 1 Lang

HTML Lang Attribute (WCAG 3.1.1)

Ensures page language is declared and valid for screen reader pronunciation

  1. Presence: Checks for lang attribute on element
  2. Validity: Validates against BCP 47 language tags (ISO 639-1/639-3)
  3. Region Codes: Accepts region subtags (en-US, zh-CN, es-MX)
  4. Inheritance: Checks child elements with different lang don't conflict
  5. Empty Value: Flags empty lang="" as error
  6. Output: Selector, actual value, expected format, severity
WCAG 3.1.1 BCP 47
Check 2 Contrast

Contrast Ratio (WCAG 1.4.3, 1.4.6)

Calculates relative luminance and contrast ratios for text and UI components

  1. Relative Luminance: Calculates per WCAG formula (sRGB linearization)
  2. Contrast Ratio: (L1 + 0.05) / (L2 + 0.05) where L1 > L2
  3. AA Normal Text: Minimum 4.5:1 contrast ratio
  4. AA Large Text: Minimum 3:1 (18pt+ or 14pt+ bold)
  5. AAA Normal Text: Minimum 7:1 contrast ratio
  6. AAA Large Text: Minimum 4.5:1 (18pt+ or 14pt+ bold)
  7. UI Components: 3:1 for borders, focus indicators, icons
  8. Color Parsing: Supports hex, rgb(), rgba(), hsl(), named colors
WCAG 1.4.3/1.4.6 AA/AAA
Check 3 Labels

Form Label Association (WCAG 1.3.1, 3.3.2)

Ensures all form inputs have accessible labels via multiple association methods

  1. Explicit Label: matching
  2. Implicit Label: Input wrapped in
  3. ARIA Label: aria-label attribute on input
  4. ARIA Labelledby: aria-labelledby referencing labeling element
  5. Title Attribute: Fallback for title (warning only)
  6. Exemptions: hidden inputs, buttons with visible text, submit/reset/image buttons
  7. Orphan Detection: Inputs with no accessible name flagged as error
WCAG 1.3.1 WCAG 3.3.2
Check 4 Alt-Text

Image Alt-Text (WCAG 1.1.1)

Validates all images have appropriate alternative text

  1. Presence: All must have alt attribute
  2. Non-Empty: Flags empty alt="" unless decorative
  3. Decorative Images: Accepts role="presentation" or alt="" for decorative
